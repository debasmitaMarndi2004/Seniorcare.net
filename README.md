# SeniorCare — modern website

Next.js App Router, TypeScript, Tailwind CSS v4. Five responsive routes based on the supplied HTML mockups.

## Run

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

## Routes

`/`, `/senior-living-options`, `/care-services`, `/resources`, `/contact`.

## Important

This is a client-facing **demo**. Forms are intentionally not connected to a backend and must not be represented as submitted. Connect a consent-aware lead handling service before production. Review all costs, ratings, testimonials, claims, contact details, and content with the client. Do not collect health information through an unsecured form. Add owned/approved photography and verify licensing before launch.
